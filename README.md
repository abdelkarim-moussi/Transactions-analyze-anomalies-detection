# Java Transactions-analyze-anomalies-detection Console App

This app is a basic Banking system build with java version 17 to digitalize bank system and detect bank accounts suspicious transactions .

### Technologies and tools used :
* IntellijIdea IDE
* Java version 17

### Project  Structure :

this project has been structured with for main layers,Entity, Service Layer , Dao layer,Presentation Layer and util, Test Layer
